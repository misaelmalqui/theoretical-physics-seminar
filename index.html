Date: April 04, 2026 Session #02

An introduction to modular invariant of string amplitudes

Speaker: Panagiotis Leivadaros

This work studies the one-loop partition function of the closed bosonic string by connecting the worldline formulation of point particles with the worldsheet description of strings. After introducing the moduli space of the torus and modular transformations, the bosonic string partition function is constructed from oscillator and zero-mode contributions. Particular emphasis is placed on modular invariance, which restricts integration to the fundamental domain and excludes the ultraviolet region ($\tau_2 \to 0$) responsible for standard field-theoretic divergences. Finally, the infrared behavior ($\tau_2 \to \infty$) is discussed, highlighting both the tachyonic divergence and the massless-mode contributions.

References & Readings:
  • Bellac, M. L. (2011). Thermal Field Theory, ser. Cambridge Monographs on Mathematical Physics. Cambridge University Press.
  • Mohaupt, T. (2022). A Short Introduction to String Theory. Cambridge University Press.
  • Polchinski, J. (1998). String Theory, ser. Cambridge Monographs on Mathematical Physics. Cambridge University Press.
